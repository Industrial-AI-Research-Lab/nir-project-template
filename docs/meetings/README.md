# Meeting records

One file per meeting, `YYYY-MM-DD.md`, copied from `0000-template.md`. Add it through a PR: the
supervisor confirms the record by approving the PR.

- Commit the record only. A transcript may be committed only after sanitization: names of third
  parties replaced by roles, no keys, addresses, grades or personal topics.
- Every decision carries a time code so it can be checked against the recording.
- Actions become issues on the board; the record links them by number.
- Prompts for cleaning a transcript, sanitizing it and drafting the record: the `meeting-record`
  skill of the overlay, or the meeting records reference in the lab manual.
